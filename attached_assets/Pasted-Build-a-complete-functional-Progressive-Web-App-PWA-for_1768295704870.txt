- **Code Structure**: Provide full code files – app/page.tsx (home), api/info/route.ts, api/download/route.ts, public/manifest.json, public/sw.js, app/layout.tsx (with ad scripts). Use Tailwind CSS for styling if easy, else basic CSS.
